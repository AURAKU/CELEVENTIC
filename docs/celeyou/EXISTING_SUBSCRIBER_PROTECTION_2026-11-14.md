# CeleYou Existing Subscriber Protection — 2026-11-14

**Status:** Implemented in tree. **Not deployed.** Release-blocking until verified on a sanitized copy of production-like records.

## Objective

Ship Free plan, optional 7-day Pro trial, and draft international catalog display **without** disrupting existing customers.

## Guarantees for existing paid subscribers

| Asset | Guarantee |
| --- | --- |
| Plan / term | Kept (`ACTIVE` / grace / courtesy). Never auto-migrated to Free. |
| Price | Historical Paystack amounts and checkout charge quotes preserved. Activation prefers charged checkout price over a later catalog change. |
| Billing period / expiry | `subscriptionExpiresAt` and remaining days preserved. Renewals refuse to shorten a live term. |
| Activation date | `lastActivatedAt` / payment link preserved. |
| Entitlements | Paid / complimentary kinds preserved. |
| Card identity | `publicToken`, slug/username, theme, designs untouched by Free/trial paths. |
| QR / NFC | Destinations not regenerated by Free/trial rollout. |
| Payment history | Advertising payments never deleted; webhook activation is idempotent on `lastActivationPaymentId`. |
| Trial | Never auto-started for paid history or active paid windows. |

## Account classification

`classifyCeleYouAccount` in `src/lib/digital-business-card/subscriber-protection.ts`:

- `existing_active_subscriber`
- `existing_expired_subscriber`
- `existing_unpaid_account`
- `existing_ambiguous_account` (preserve access semantics; flag for review)
- `new_free_account`
- `new_trial_account`
- `new_paid_subscriber`

**Rule:** Do not assume “no `CeleYouTrialRecord`” means Free.

## Feature flags (safe defaults)

| Flag | Default | Meaning |
| --- | --- | --- |
| `CELEYOU_FEATURE_FREE_PLAN` | `true` | New / eligible unpaid Free presentation |
| `CELEYOU_FEATURE_PRO_TRIAL` | `true` | Optional Pro trial for eligible accounts |
| `CELEYOU_FEATURE_INTERNATIONAL_PRICING` | `false` | Draft display only; checkout stays GHS Paystack |
| `CELEYOU_FEATURE_AUTO_APPLY_FREE_TRIAL_TO_LEGACY` | `false` | Never auto-apply Free/trial to legacy/ambiguous |

## Database migration safety

`prisma/migrations/20261114210000_celeyou_freemium_trial/migration.sql` is **additive only**:

- Adds trial tables and lifecycle policy columns.
- Does **not** `UPDATE` / `DELETE` `digital_business_cards`.
- Does **not** rewrite `subscriptionStatus`, expiry, tokens, or payments.

Schema default `subscriptionStatus = FREE` applies to **new inserts only**.

## Trial eligibility policy (legacy unpaid)

Documented in `CELEYOU_LEGACY_TRIAL_POLICY`:

- Completed legacy studio `TRIAL` windows do not get a second Pro trial.
- Any paid activation, advertising SUCCESS payment, or complimentary entitlement never receives an automatic Pro trial.
- Ambiguous statuses keep protected semantics and are flagged for review.

## Rollout sequence (do not skip)

1. Architecture + flags in tree (done).
2. Local / sanitized-copy audit script.
3. Verify entitlements for monthly / quarterly / half-yearly / yearly fixtures.
4. Verify payment idempotency and expiry math.
5. Deploy compatible backend only after acceptance.

## Acceptance

Existing active subscribers must experience no unintended change to access, pricing, duration, renewal terms, premium benefits, card identity, QR/NFC, or payment records.

If compatibility cannot be verified → **block rollout**.

**Do not deploy automatically.**
